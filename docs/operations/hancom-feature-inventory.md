# 한글 메뉴 대비 K-Doc 기능 표 (2026-11-03)

기준: 한컴오피스 한글(맥) 내장 도움말 `Help/menu/*.htm` 의 메뉴 항목 전부. 코드 읽기로 판정했다(빌드 없이).

상태: ✅ 있음 · 🟡 일부(모자란 점 적음) · ⬜ 껍데기(메뉴만) · 🔧 엔진만(사람이 닿을 길 없음) · ❌ 없음
일: 화면 = 화면 코드만 / 엔진 = Rust 엔진도 / 밖 = 사전·양식 같은 외부 자원 필요. 크기 S 반나절 · M 하루 · L 여러 날.
「처리」 열은 이 표를 만든 뒤 채운 것(가지 `feat/hancom-parity`).

## 순서

1. 화면만으로 되는 S 묶음 + 표 안의 표 대화상자 버그 막기
2. 엔진 M 묶음(쪽 번호 매기기·각주 모양·글자 겹치기·각주/미주 변환·문자열↔표·날짜 코드·요약 정보 필드·표 안의 표 구조 편집 …)
3. L 묶음(메모·덧말·글맵시·차트·바탕쪽·세로쓰기·차례·첫 글자 장식 …)
4. 외부 자원(맞춤법·한자·문서마당·원고지·라벨)은 자원 출처를 정한 뒤
