# 한글 기본 편집 빈칸 채우기 1-Pager (2단계)

## Background

2026-11-02 사용자 결정: 사람 편집은 한글 기본 기능(표·그림·표에 그림·표에 글자·표 수정·테두리 등)을
한글과 똑같이 불편 없이 쓸 수 있어야 한다. 1단계(에이전트 화면 일치, v0.2.3)는 끝났다
([agent-parity-1pager.md](agent-parity-1pager.md)).

## Problem (조사 2026-11-03)

1. **메뉴에 없는 기능**: 엔진·명령은 있는데 K-Doc 메뉴(HOP 시절 `apps/studio-host/index.html`)에 없다 —
   수식, 모양 붙여넣기, 쪽 테두리/배경, 각주/미주 모양, 행/열 바꿈, 격자, 배율 창, 주석 편집 도구상자.
2. **표 셀 안 수식**: 셀 안에서 수식 넣기가 꺼져 있다. 한 셀 문단에 수식이 여럿이면 두 번째부터 눌러도
   첫 수식이 고쳐진다(수학 시험지 표본 `3-09월_교육_통합_*.hwp` 에서 같은 주소 ×2~4 확인).
3. **표 셀 안 그림**: 셀에 그림을 넣으면 표 문단 옆 종이 기준 그림으로 뜬다. 한글 기본(마우스로 크기 지정 끔)은
   셀 문단 안 자리차지 그림이라 셀과 함께 움직인다(표본 `ta-pic-cell-*.hwpx`).
4. 그 밖: 쪽 번호 넣기, 캡션 위치 메뉴, 셀 테두리/배경 도구, 표 안의 표 구조 편집(패치 0009 가 막음),
   메모·문단 띠, 그림 자르기 손잡이.
